# Учёт промышленных отходов

Десктоп-клиент дипломного проекта — модуль **«Учёт»** для платформы учёта отходов на предприятии.  
Приложение работает с REST API бэкенда: регистрация партий, справочник ФККО, контроль классификации, учёт переработки и вывоза, формирование отчётов.

| | |
|---|---|
| **Стек** | C#, WPF, .NET 8 |
| **API** | `http://178.57.217.79:8080/api/v1` |
| **Swagger** | http://178.57.217.79:8080/docs |
| **Репозиторий** | https://github.com/AnabanPy/Diplom-application |

---

## Возможности программы

### Оператор склада
- просмотр **истории поступлений** партий;
- **регистрация новой партии** с выбором вида отхода из справочника ФККО;
- автоматическая генерация кода партии (P1, P2, …);
- указание объёма, единицы измерения, класса опасности, срока хранения, цеха-источника.

### Начальник склада
- история партий с балансом (поступило / переработано / вывезено / остаток);
- **операции** — запись переработки, утилизации, вывоза, передачи;
- **отчёты и аналитика** — фильтры, сводка с dashboard, экспорт в Excel и Word;
- **контроль классификации** — просмотр очереди (без подтверждения);
- **справочник ФККО** — полный каталог (~9000 позиций) с сервера.

### Эколог / администратор
- всё, что доступно начальнику;
- **подтверждение и отклонение** партий в очереди классификации;
- просмотр **истории классификации** по партии.

## Запуск

### Требования
- Windows 10 / 11
- [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)
- доступ в интернет (сервер API)

### Как запустить
1. Двойной клик по **`Run.bat`** в корне репозитория
2. Или напрямую: **`WasteAccountingClient.CSharp\dist\win-x64\WasteAccountingClient.exe`**

### Пересборка
```bat
cd WasteAccountingClient.CSharp
Собрать-релиз.bat
```
Собранный exe появится в `WasteAccountingClient.CSharp\dist\win-x64\`.

## Вход в систему

На экране авторизации введите email и пароль. Роль определяется сервером после входа.

| Роль | Email | Пароль | Назначение |
|------|-------|--------|------------|
| Оператор | `operator@eco.local` | `operator123` | Регистрация партий |
| Начальник | `chief@eco.local` | `chief123` | Операции, отчёты, контроль |
| Эколог | `ecologist@eco.local` | `ecologist123` | Классификация, отклонение |
| Администратор | `admin@eco.local` | `admin123` | Полный доступ как у эколога |

## Справочник ФККО

Каталог загружен с официального источника [rpn.gov.ru/fkko](https://rpn.gov.ru/fkko/) (~9000 позиций).

| Кто | Откуда берётся справочник |
|-----|---------------------------|
| chief / ecologist / admin | Сервер `GET /core/waste-types` |
| operator | Локальный **`fkko_operator.json.gz`** (~200 KB, 6656 видов) — сервер не выдаёт operator доступ к API |

При **регистрации партии**:
- в поиске вводите **минимум 2 символа** (название или код ФККО);
- показываются только **конкретные виды отходов** (класс I–V), без групповых разделов каталога;
- после выбора наименование, код ФККО и класс опасности подставляются автоматически.

При просмотре **справочника ФККО** (начальник/эколог) — полный каталог с сервера, сортировка по коду ФККО с `1 00 000 00 00 0`.

## Интеграция с API

Клиент использует JWT-авторизацию. Основные эндпоинты:

| Действие | Метод | Путь |
|----------|-------|------|
| Вход | POST | `/auth/login` |
| Профиль | GET | `/auth/user` |
| Справочник ФККО | GET | `/core/waste-types` |
| Список партий | GET | `/accounting/batches` |
| Регистрация партии | POST | `/accounting/batches` |
| Классификация | PATCH | `/accounting/batches/{id}/classify` |
| Отклонение | PATCH | `/accounting/batches/{id}/reject` |
| Баланс партии | GET | `/accounting/batches/{id}/balance` |
| Операции | GET/POST | `/accounting/operations` |
| Dashboard | GET | `/reporting/dashboard` |

## Ограничения текущей версии

- нет экрана профиля и смены пароля;
- нет админ-панели управления пользователями;
- operator не имеет доступа к API справочника ФККО (используется локальная копия ~200 KB);
- начальник не может подтверждать/отклонять классификацию — только просмотр.
